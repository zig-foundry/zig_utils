# zig_utils

Small and practical helper functions for Zig that extend the standard library.

## Features

- Read single lines cleanly from standard input or any OS file handle.
- Parse standard input directly into integers, floats, booleans, and enums.
- Built for Zig `0.18.0-dev` with zero external dependencies.

## Examples

Check the `examples/` directory to see how to use `zig_utils` in your project.

## Commands

- Run tests: `zig build test`
- Check compilation: `zig build check`
- Build docs: `zig build docs`
